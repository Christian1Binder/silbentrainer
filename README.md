# Silbenhelden

Eine iPad-optimierte Lern-App zum Zusammensetzen von Sätzen aus Silben.

## Funktionen

- drei Schwierigkeitsgrade für Grundschule, Sekundarstufe und Oberstufe
- jeweils 50 Sätze pro Niveau
- zehn zufällige Aufgaben pro Runde
- Drag-and-drop und Antipp-Bedienung
- Sterne, XP, Serien und Abzeichen
- lokaler Lernfortschritt im Browser
- deutsche Vorlesefunktion
- ohne Framework und ohne externe Abhängigkeiten

Die App kann direkt über GitHub Pages veröffentlicht werden. Als Quelle genügt der Branch `main` mit dem Stammverzeichnis `/root`.
